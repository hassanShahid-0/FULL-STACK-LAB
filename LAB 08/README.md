# Complete Node Revision Lab Solutions
Eight separate folders correspond to Problems 1–8 in the supplied lab document.

## Requirements
- Modern browser for Problems 1–3.
- Node.js for Problems 3–8.
- Postman for Problem 6.
- Problem 2 uses ES modules: run a local static server (for example VS Code Live Server), do not open its HTML as a file URL.
- Problem 4: `node app.js list` or `node app.js loan LAP-001 2`.
- Problem 5: `node server.js` (port 3000).
- Problem 6: import its collection and environment JSON into Postman while Problem 5 is running.
- Problem 7: run `npm install`; in two terminals run `npm run smtp` and `npm run api` (ports 1025 and 3001).
- Problem 8: run `npm install`, then `npm start` (port 3002).

## Restrictions followed
No Express, React or database. Backend storage uses JSON/text files. The SMTP exercise targets only a local receiver. Do not submit node_modules, passwords or private uploaded documents.

Run the normal and error tests yourself and capture screenshots. Do not claim a test passed before running it. Write your own 150–250 word reflection covering one design choice, one bug and one improvement.
